# Бот парикмахерской (Telegram)

## Что внутри
- Обязательная регистрация: имя + принятие пользовательского соглашения (без
  согласия пользоваться ботом нельзя). Телефон не запрашивается.
- Программа лояльности привязана к внутреннему ID пользователя (создаётся
  автоматически при регистрации). Сам пользователь этот ID не видит, но он
  показывается администратору — в тикетах, при бане и в Excel-выгрузке.
- Главное меню с фото (`photo.jpg`)
- Запись: мастер → услуга → дата (календарь 🟩/🟥 — видно, где есть свободные
  окна) → время. Защита от злоупотреблений: лимит активных записей на
  клиента и запрет самому себе бронировать два места на одно время.
- Профиль: мои записи, система лояльности (промокоды + акции), мои тикеты,
  вкл/выкл уведомлений
- FAQ с пользовательским соглашением
- Поддержка: создание тикета, переписка с админом, закрыть тикет может только админ
- Система банов: администратор банит/разбанивает пользователей по ID с
  указанием причины; забаненный видит причину и может подать апелляцию
  (создаётся тикет с автотемой), администратор одобряет или отклоняет её
  прямо в тикете
- Панель администратора (виден только вашему ID): тикеты (+апелляции),
  отмена записей, добавление и управление мастерами (фото/описание/услуги,
  отпуск по календарю, удаление), баны, скидки/акции, выгрузка
  пользователей/записей в Excel-файл
- Push-напоминания за 3 часа и за 1 час до записи (с учётом настроек уведомлений)

## Установка (Linux/Windows/Mac)

1. Установите Python 3.10+
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Положите фото для главного меню рядом с `main.py` под именем `photo.jpg`
4. Создайте файл `.env` рядом с `main.py` (шаблон — `.env.example`):
   ```
   BOT_TOKEN=токен_из_BotFather
   ADMIN_IDS=ваш_telegram_id
   ```
5. Запустите бота:
   ```
   python main.py
   ```
6. Бот должен работать постоянно (24/7) — иначе не будут приходить
   напоминания. Проще всего разместить на VPS через `systemd`/`pm2`/
   `screen`/`tmux`/Docker — спросите меня, помогу с деплоем.

## Токен и админ

Токен бота и Telegram ID администратора берутся из файла `.env`
(секреты не хранятся в коде). Файл `.env` никогда не публикуйте —
он уже добавлен в `.gitignore`.
Если токен «утёк» — перевыпустите его в @BotFather командой `/revoke`.

## Регистрация и программа лояльности

Телефон не запрашивается вообще. При регистрации бот спрашивает только имя,
затем показывает пользовательское соглашение — без нажатия «✅ Я согласен(на)»
регистрация не завершится и бот останется недоступен.

Идентификатор для программы лояльности — это внутренний `ID` пользователя
(обычное число, создаётся автоматически). Пользователь его не видит нигде в
интерфейсе, но администратор видит этот ID:
- в карточке пользователя при бане,
- в тикетах поддержки,
- в Excel-выгрузке («📊 Данные пользователей»).

## Система банов и апелляций

`Панель администратора → 🚫 Баны`:
- **«Все пользователи»** — список всех, тап → «Забанить» → ввести причину
  текстом. Пользователь сразу получает сообщение о блокировке с указанной
  причиной и кнопкой апелляции.
- Забаненный пользователь при нажатии любой кнопки бота видит сообщение
  «Вы заблокированы» + причину. Кнопка **«📮 Обжаловать блокировку»**
  создаёт тикет с автоматической темой «Апелляция бана» — переписываться в
  нём можно как в обычном тикете.
- В самом тикете-апелляции у администратора две дополнительные кнопки:
  **«✅ Одобрить апелляцию»** (снимает блокировку, пользователь получает
  сообщение об успешной разблокировке) и **«❌ Отклонить»** (блокировка
  становится постоянной, повторно подать апелляцию через бота уже нельзя).
- **«Забаненные (разбанить)»** — список всех забаненных; администратор может
  снять бан в любой момент, даже если апелляция была отклонена и блокировка
  считается постоянной.

## Управление мастерами

`Панель администратора → ➕ Добавить мастера` — пошагово: имя → описание →
фото (или «Без фото») → отметить услуги, которые он оказывает (мультивыбор).

`Панель администратора → 🗂 Управление мастерами` — список существующих
мастеров, у каждого:
- **«🏖 Управление отпуском»** — календарь на ближайшие дни: 🟩 значит у
  мастера в этот день есть свободные окна, 🟥 — либо все слоты заняты, либо
  день уже отмечен как выходной/отпуск. Нажатие на дату ставит или снимает
  статус «выходной». Если на день уже есть активные записи клиентов,
  поставить выходной нельзя — бот попросит сначала отменить эти записи
  (раздел «📅 Записи (удалить)»).
- **«🗑 Удалить мастера»** — с подтверждением. Мастер исчезает из всех
  списков (клиенты его больше не видят и не могут записаться), но история
  уже сделанных им записей и отчётность сохраняются. Если у мастера есть
  активные записи — сначала нужно их отменить.

Тот же 🟩/🟥-календарь показывается и клиентам при выборе даты записи —
сразу видно, к какому мастеру и на какой день есть свободные окна.

## Что легко поменять в `config.py`
- Цены и названия услуг — `CATEGORIES`
- Часы работы и шаг слотов записи — `WORK_START_HOUR`, `WORK_END_HOUR`, `SLOT_MINUTES`
- На сколько дней вперёд доступна запись (и календарь отпуска) — `DAYS_AHEAD`
- Лимит активных записей на одного клиента — `MAX_ACTIVE_BOOKINGS`
- Текст пользовательского соглашения и FAQ — `TERMS_TEXT`, `FAQ_TEXT`

## Дополнительные команды администратора
```
/addmaster Имя мастера     → быстрое добавление без фото/услуг (видит все услуги)
/addpromo КОД 15           → создать промокод КОД со скидкой 15%
```

## Структура проекта
```
salon_bot/
├── main.py                # точка входа
├── config.py               # услуги, тексты, часы работы (токен и админ — в .env)
├── database.py              # вся работа с SQLite (файл salon.db создастся сам)
├── keyboards.py             # инлайн-клавиатуры
├── states.py                # состояния диалогов (FSM)
├── middleware.py            # проверка регистрации и банов
├── scheduler.py              # push-напоминания за 3ч / 1ч
├── requirements.txt
└── handlers/
    ├── registration.py       # регистрация (имя + соглашение) + главное меню
    ├── booking.py             # запись на услугу, календарь занятости
    ├── profile.py             # профиль, записи, лояльность, тикеты, уведомления
    ├── support.py             # создание и переписка в тикетах
    ├── masters.py             # список мастеров (клиентский) + FAQ
    ├── banning.py             # баны, апелляции, разбан
    └── admin.py               # панель администратора: тикеты, записи, мастера, скидки, экспорт
```
